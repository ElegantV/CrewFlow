推荐**方案 A：改底部半屏 sheet + 图标化列表行**：

- 去掉 `.menu-editor__switch { transform: scale(.72) }`（缩放使原生 switch 发虚）。
- 底部：取消改描边幽灵按钮降权重，保存保持主色实心；加 env(safe-area-inset-bottom)。
- **顺手修 token 违规**：`<switch color="#2f6fed">` 硬编码在 wxml（正是被归并的散落蓝之一）。switch 的 color 属性不吃 CSS 变量，建议新建 `utils/theme.js` 导出 `BRAND_DEEP='#2f6fed'` 并注明与 --brand-deep 同步。

## 编辑菜单弹窗改造（已实现并提交）

新建 `utils/theme.js`：导出 `BRAND='#1677ff'` / `BRAND_DEEP='#2f6fed'`。原因是小程序 `switch` 的 `color` 属性走原生通道、不接受 CSS 变量，只能从 JS 传值；文件头注释要求与 app.wxss 的 `--brand` / `--brand-deep` 同步。

改动：
- `pages/index/index.js`：引入 theme 并在 data 加 `switchColor`；`openMenuEditor` 的 map 补 `icon`/`accent`；`closeMenuEditor` 改为先置 `menuClosing` 播收起动画、200ms 后再卸载节点（新增 `onUnload` 清定时器，`saveMenuEditor` 成功分支也清定时器）。
- `pages/index/index.wxml`：居中卡片 → 底部 sheet，加 handle / 标题行带 ✕ / scroll-view 列表；每行结构为「序号 + 彩色图标 + 标题+状态两行 + switch + ↑↓」；首尾项的箭头加 `--disabled` 类。`switch color` 改为 `{{switchColor}}`。
- `pages/index/index.wxss`：`.menu-editor__*` 全部重命名为 `.menu-sheet__*` / `.menu-item__*`；新增 `@keyframes mask-fade` 与 `sheet-rise`（`cubic-bezier(.32,.72,0,1)`），关闭用 `animation ... reverse forwards`；图标去色用 `filter: grayscale(1)` + `opacity:.4`（避免与各 accent 的 background 规则抢特异性）；箭头点击区 52rpx→64rpx；补 `env(safe-area-inset-bottom)`。
- 复用首页既有的 `.shortcut--{accent} .shortcut-icon` 取色，未新增装饰色。

校验：`node --check` 两个 js 通过；脚本核对 index.wxss 引用的 22 个 token 全部在 app.wxss 有定义；7 个 accent 值（ai/blue/green/orange/purple/red/slate）均有对应规则；无 `menu-editor` 残留引用。**本环境跑不了微信开发者工具，未做编译与真机预览。**

# CrewFlow 一期业务规则

## 角色

- 超级管理员：拥有全部权限，可维护用户角色、状态和审批管理员。
- 管理员：审批分配给自己的普通用户请假，一个管理员可以对应多个用户。
- 普通用户：登记加班、申请请假、维护自己的工作代理人。
- 请假采用一级审批，代理人无需确认。

## 加班与调休

- 新增加班直接填写加班时长，不再要求用户选择结束时间。
- 每次可登记 2 至 6 个整小时；服务端以 17:30 为起点推导结束时间用于历史记录展示。
- 允许补录任意过去日期的加班，不允许登记未来日期。
- 同一用户同一天只能存在一条未撤销加班。
- 调休额度在加班日起三个月到期。
- 调休申请按到期时间最早、加班日期最早的顺序分配。
- 已被调休使用的加班不能直接撤销，需先撤销对应请假。
- 请假撤销或驳回时，额度退回原加班记录，原到期日不变；如果原记录已经
  到期，退回额度立即到期。

## 假期

| 类型 | 最小单位 | 材料提示（不在系统上传） |
| --- | ---: | --- |
| 调休、公出、哺乳假 | 4 小时 | 无 |
| 年假、事假、产检假、产假、育儿假 | 8 小时 | 无 |
| 病假 | 8 小时 | 病例或诊断材料 |
| 丧假 | 8 小时 | 死亡证明 |
| 婚假 | 10 个工作日，一次性休完 | 结婚证 |
| 陪产假 | 15 个工作日，一次性休完 | 出生证明 |

工作日暂按周一至周五计算，尚未接入法定节假日和调休工作日历。

## 重复与并发

- 待审批或已通过的日期区间发生重叠时，拒绝新申请并返回冲突日期。
- 服务端事务锁定加班余额，防止多个请求重复占用同一额度。
- 已处理的审批不能再次操作。

## 待后续确认

- 法定节假日、调休工作日的日历来源。
- 产假、产检假、育儿假的年度或总额度。
- 年假余额的导入与结转规则。
- 请假开始日期是否允许补录过去日期。
- 证明材料的保留期限和删除策略。

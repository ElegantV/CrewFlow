# CrewFlow 小程序样式美化方案

> 分析日期：2026-09-04
> 对象：`CrewFlow/pages/*`（12 个页面）+ `components/*`（month-records、navigation-bar）
> 结论先行：设计语言底子不差，但**设计令牌（design token）没有真正落地**——颜色、圆角、间距散落在各页面，跨页面/跨组件各自实现，导致「同语义不同色、改主题要动 N 处」。这是美化投入产出比最高的一件事。

---

## 0. 做得好的地方（先肯定，避免只挑刺）

- 全局 token 雏形已存在：`app.wxss` 里有 `.card` `.primary-button` `.muted` `.tap-active` `.page-shell`，且被各页面广泛复用。
- 间距节奏统一：`page-shell`(24/28/32rpx)、卡片内边距、section 标题层级在 index/leave/duty 上一致。
- 交互模式成型：底部固定操作条（`.action-bar`）、底部/居中弹层表单（`.form-card`）、自定义日历组件、自定义导航栏（`navigation-bar`）都已模块化。
- 状态徽章用胶囊样式（`border-radius:999rpx`），语义清晰。
- 首页 hero、reminder 卡、菜单编辑器弹层的视觉完成度很高。

---

## 1. P0 —— 设计令牌集中化（影响最大）

### 1.1 颜色碎片化：21+ 个 hex，且同一种语义多种色

全量扫描 `pages/*/*.wxss` 得到的色板（去重计数 top）：

| 语义 | 现用色（散落各处） | 问题 |
| --- | --- | --- |
| 主蓝 | `#1677ff`(17×) / `#2563eb`(9×) / `#246bfd`(4×) / `#2f6fed`(JS) | **4 种蓝并存** |
| 浅蓝底 | `#edf5ff` / `#eff6ff` / `#f1f5f9` / `#edf2f7` | 同一种"高亮底"至少 4 个写法 |
| 中性灰(文字) | `#718096`(21×) / `#64748b` / `#8a9099` / `#8a96a6` / `#7b8797` / `#7b8494` / `#8a93a2` / `#949cab` | 近 8 个肉眼难分的灰 |
| 红 | `#dc2626`(审批驳回/录音) / `#f43f5e`(台账请假标签) / `#a23a3a`(assistant 错误泡) | 同一"警示"3 色 |
| 绿 | `#047857` / `#059669` / `#16875d` / `#21b879`(在线点) / `#10b981`(台账加班标签) | 同一"成功/通过"多色 |
| 琥珀 | `#92400e`/`#fffbeb`(index/admin/台账) / `#684b12`/`#fff8e8`(assistant clarify) / `#fef3c7`(台账 consumed) | 同一"待/提醒"3 套 |

**具体证据：**
- `pages/index/index.wxss:115` 快捷方式图标用 `#2563eb`；`app.wxss` 主按钮用 `#1677ff`；`pages/assistant/index.wxss:41` 头像渐变用 `#246bfd` → 主蓝三处不一。
- `pages/month-records/month-records.wxss:12-13` 请假标签 `#f43f5e`、加班标签 `#10b981`，与 `pages/approval/index.wxss:7,14-15` 的 leave-type 蓝 `#2563eb`、通过绿 `#059669`、驳回红 `#dc2626` 完全是两套语义色。
- `pages/assistant/index.wxss:62-63,71-74` 自己又有一套 online/error/success/clarify/running 配色，全不与他人对齐。

**建议：** 在 `app.wxss` 用 CSS 变量定义一套令牌（见附录），全量替换。改主题/换肤只动一处。

### 1.2 圆角/间距未统一

- 卡片 `20rpx`、表单控件 `14~18rpx`、胶囊 `999rpx`、气泡 `8rpx 24rpx 24rpx` 混用无约束。
- `pages/assistant/index.wxss:94` 输入框 `10rpx`、`send-button` `10rpx`，与全局 `14~18rpx` 不一致。
- 建议：定义 `--cf-radius-card / --cf-radius-control / --cf-radius-sheet / --cf-radius-pill` 与 `--cf-gap / --cf-page-pad`。

## 2. P1 —— 共享组件抽进全局

以下类在 **5+ 个页面各自定义一份**（内容往往完全相同，纯复制）：

| 类 | 重复出现的文件 |
| --- | --- |
| `.secondary-button` | `leave` 与 `duty` 完全相同（`color:#475569;background:#edf2f7`），却复制两份 |
| `.modal-mask` / `.form-card` / `.sheet-head` / `.sheet-handle` | `index` / `leave` / `duty` / `admin` |
| `.field` / `.field-control` / `.field-label` / `.form-actions` | `leave` / `duty` / `admin` / `register` |
| `.status--*` | `leave` / `duty` / `admin`（状态配色三套） |
| `.action-bar` | `leave` / `duty` |

**建议：** 把弹层、表单字段、次按钮、底部操作条、空/加载态、状态徽章全部收进 `app.wxss`，各页面只写布局。改一处即全站统一。

### 2.1 底部弹层形态不统一（顺手修）

- `leave` / `duty`：`.form-card` 是**居中 modal**（无顶部圆角）。
- `admin`：`pages/admin/users.wxss:12` `.form-card` 是**底部 sheet**（`border-radius:32rpx 32rpx 0 0`）。
- 同一"表单弹层"两种形态，建议统一为底部 sheet（移动端更顺手）或统一居中 modal。

### 2.2 导航栏背景硬编码

每个页面的 `<navigation-bar background="#F7F8FA">` 都把背景色写死在 WXML（`pages/*/index.wxml` 首行）。若全局换肤，要改 12 处。建议导航栏背景跟随 `page` 背景变量（或组件内默认读取全局变量）。

## 3. P2 —— 体验与细节打磨

### 3.1 空/加载态缺失（5 个页面）

扫描结果：admin、assistant、index、ledger、register **缺少 empty/loading 态**；leave/duty/approval/contact/dev/situation/profile 已覆盖。

- `ledger` 依赖 `month-records` 组件（组件内已有 `records-empty/records-loading`，OK）。
- `index` 是仪表盘、可容忍；但 **admin 用户列表、assistant、register** 列表/结果区为空时直接空白，像坏了一样。补齐统一的 `.empty` / `.loading`（P1 已提到抽到全局）。

### 3.2 安全区适配不一致

仅 `pages/index/index.wxss:14` 处理了 `env(safe-area-inset-bottom)`。底部操作条 `.action-bar` 各页是否留安全区需逐一确认，建议统一在 `.action-bar` 内处理。

### 3.3 按钮高度不统一

- `.primary-button`(app) 88rpx、`.hero-button`(index) 64rpx、`.tab--active`(register)、`.retry-button`、`send-button`(assistant) 76rpx 各异。
- 主操作按钮建议统一高度与圆角，强化"可点"的一致性感知。

### 3.4 低对比小字

- `#9aa5b3`(situation `panel-tip` 19rpx)、`#8a96a6`(situation 周标签)、`#9aa2af`(assistant `composer-hint` 19rpx) 在白底上对比度偏低，小字更难辨认。
- 统一到 `--cf-text-3`（不低于 `#64748b` 量级），19rpx 提示字建议不低于 20rpx 或加深。

### 3.5 文本截断不一致

- 多数列表项已用 `ellipsis` + `nowrap`（如月台账 `record-sub`）；但 `request-meta`、部分 `record-content` 未截断，长内容会换行撑高卡片，破坏节奏。统一截断规则。

## 4. 改造优先级

| 优先级 | 项 | 收益 |
| --- | --- | --- |
| **P0** | `app.wxss` 落地颜色/圆角/间距 CSS 变量，全量替换散落 hex | 消除 80% 视觉不一致，换肤一处搞定 |
| **P0** | 统一状态/语义色板（请假/加班/通过/驳回/待审/在线） | 同一语义处处同色 |
| **P1** | 弹层/表单/次按钮/操作条/空态/状态徽章抽到全局 | 改样式不动 N 处 |
| **P1** | 底部弹层形态统一 + 导航栏背景变量化 | 交互一致 |
| **P2** | 补空/加载态、安全区、按钮高度、低对比小字、截断 | 打磨完成度 |

**一句话建议**：先做 P0 那一个 `app.wxss` 令牌文件 + 把表单/弹窗/空态/状态徽章抽成全局类，就能消掉绝大多数不一致，且后续每个新页面直接套 token，不用再各自调色。

## 附录：建议的 `app.wxss` 设计令牌草案

```css
/* ===== CrewFlow 设计令牌 ===== */
page {
  --cf-primary: #1677ff;
  --cf-primary-strong: #0e5fd8;
  --cf-primary-soft: #eff5ff;     /* 统一 edf5ff/eff6ff/f1f5f9 */
  --cf-danger: #dc2626;
  --cf-danger-soft: #fef2f2;
  --cf-warning: #92400e;
  --cf-warning-soft: #fffbeb;     /* 统一 fffbeb/fff8e8/fef3c7 */
  --cf-success: #047857;
  --cf-success-soft: #ecfdf5;     /* 统一 ecfdf5/ebfaf3 */
  --cf-text-1: #1f2329;
  --cf-text-2: #475569;
  --cf-text-3: #718096;           /* muted，统一 64748b/8a9099/8a96a6… */
  --cf-text-4: #94a3b8;           /* 仅用于 20rpx+ 提示字 */
  --cf-fill-1: #f5f7fa;           /* 页面交替底 */
  --cf-fill-2: #edf2f7;
  --cf-border: #edf0f5;           /* 卡片描边 */
  --cf-divider: #f0f2f5;          /* 列表分隔线 */
  --cf-radius-card: 20rpx;
  --cf-radius-control: 16rpx;
  --cf-radius-sheet: 28rpx;
  --cf-radius-pill: 999rpx;
  --cf-gap: 24rpx;
  --cf-page-pad: 28rpx;

  min-height: 100%;
  background: #f7f8fa;
  color: var(--cf-text-1);
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
}
```

> 说明：选 `#1677ff` 作主蓝是因为它已是 `app.wxss` 里 `.primary-button` 的取值，改动面最小；`#2563eb`/`#246bfd` 统一收口到它。`--cf-text-4` 仅允许用于 ≥20rpx 的辅助字，避免低对比。
